# 辅助损失修复：使用未归一化特征 + 移除 bias

**日期**: 2026-05-24
**会话概况**: 修复 main_joint.py 中辅助损失（aux_head）的设计问题：原代码将 L2 归一化后的特征传入辅助头，且 nn.Linear 使用了 bias，与设计意图不符。

---

## 1. 修改内容

### 文件 1: `src/trainers/lora_nsp_trainer.py`

**问题 1**: `aux_head = nn.Linear(feature_dim, num_classes)` 使用 `bias=True`（默认）
- 主分类器使用 `img_feats @ classifier` 是纯余弦相似度（origin-centered）
- 辅助头有 bias 意味着决策边界可以偏离原点，与推理时的评估方式不一致
- **修复**: 改为 `nn.Linear(feature_dim, num_classes, bias=False)`

**问题 2**: 辅助头接收 L2 归一化后的特征
- 原代码 `img_feats = self.encode_image(images)` → 已归一化
- 辅助头的设计目的是帮助 LR-RGDA（高斯判别分析），后者在原始欧氏空间中建模
- 归一化会丢失特征的幅度信息，削弱辅助头的作用
- **修复**: 将单次前向改为 `vision_model → visual_projection → normalize` 三步，辅助头在 `visual_projection` 输出（未归一化）上计算

```python
# 改前
img_feats = self.encode_image(images)
img_feats = img_feats / img_feats.norm(dim=-1, keepdim=True)
if aux_head is not None:
    aux_logits = aux_head(img_feats)  # ← 归一化特征

# 改后
vision_outputs = self.model.vision_model(images)
pooled = vision_outputs[1]
proj_feats = self.model.visual_projection(pooled)  # 512-dim 未归一化
norm_feats = F.normalize(proj_feats, dim=-1)  # 512-dim 已归一化
if aux_head is not None:
    aux_logits = aux_head(proj_feats)  # ← 未归一化特征
```

### 文件 2: `main_joint.py`

- `run_full_evaluation()` 新增格式化表格输出（来自上一轮改动）
