# Gate Status Artifact Policy

**Date**: 2026-06-14

## Context

`verify_publication_package.sh` now writes:

```text
experiments/publication_gate_status.json
experiments/publication_gate_status.md
```

These files live under `experiments/`, which is ignored by `.gitignore`. They
are generated snapshots of the current gate dashboard, not source files to edit
by hand.

## Changes

Updated:

```text
experiments/README_publication_repro.md
```

The README now states that these gate status artifacts are regenerated by the
verifier or remote postprocess command and should not be manually edited.
