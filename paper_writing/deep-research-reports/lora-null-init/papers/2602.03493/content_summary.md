> **Authors**: Alessio Quercia, Arya Bangun, Ira Assent, Hanno Scharr (2026)
> **arXiv**: 2602.03493

## 1. 问题定义

### 核心问题

LoRA 系列方法在微调大模型时面临一个根本性挑战：**如何平衡"下游任务性能"与"灾难性遗忘预训练知识"**。现有方法提供了不一致的建议：

- **PiSSA** (Meng et al., 2024)：微调**最大奇异值对应的主成分（首分量）**，认为这样可以最大化下游任务适应能力。
- **MiLoRA** (Wang et al., 2024a)：微调**最小奇异值对应的次要成分（末分量）**，认为这样可以最小化对预训练知识的干扰。

两者都没有全面分析"哪些成分"最适合微调——它们只关注了谱的两端。

### 研究目标

1. 系统性地分析 LoRA 初始化中不同主成分对 **performance-forgetting trade-off** 的影响。
2. 提出一种基于**中间主成分**的初始化策略，在性能和遗忘之间实现更优的平衡。
3. 揭示为什么极端主成分（首/末）在长时间训练或高学习率下更容易导致遗忘。

### 研究范围

- **视觉任务**：ImageNet1k 预训练的 ViT-Base → 11个分类数据集（CIFAR10/100, Caltech101/256, Food101, Oxford Pets/Flowers, Stanford Cars/Dogs, DTD, FGVC Aircraft）
- **NLP 任务**：LLaMA-2 7B → Python 编程 (Human-eval, MBPP)、数学推理 (Math)、常识推理 (Commonsense)

## 2. 核心方法

### 2.1 统一框架：Generalized LoRA Initialization

给定预训练权重矩阵 $W \in \mathbb{R}^{m \times n}$，对其进行 SVD：

$$W = U D V^T$$

其中 $U \in \mathbb{R}^{m \times m}$, $D \in \mathbb{R}^{m \times n}$（奇异值对角矩阵），$V^T \in \mathbb{R}^{m \times n}$。

论文定义一个**广义的 LoRA 初始化方法**，用两个参数 $(s, r)$ 控制：

- $s$：起始主成分索引
- $r$：LoRA 的秩

选择从 $s$ 到 $s+r$ 的主成分，定义 LoRA 矩阵：

$$A = U_{s:s+r} \cdot \sqrt{D_{s:s+r}}, \quad B = \sqrt{D_{s:s+r}} \cdot V_{s:s+r}^T$$

前向传播为：

$$Y = X(W_0 + \Delta W) = X(W_0 + AB)$$

其中 $W_0 = W - U_{s:s+r} D_{s:s+r} V_{s:s+r}^T$ 是**冻结的残差预训练矩阵**。

> **关键关系**：
> - **PiSSA** 是该框架的特例：$s = 0$（选取**首 r 个**主成分）
> - **MiLoRA** 是该框架的特例：$s = m - r$（选取**末 r 个**主成分）
> - **本文方法**：选取 $0 < s < m-r$ 的**中间**主成分

### 2.2 "中间"到底指什么？

"中间主成分"并非指几何意义上的居中，而是指**既不是最大奇异值对应的成分，也不是最小奇异值对应的成分**。

**具体数值示例**：

| 模型 | 总奇异值数(m) | LoRA 秩(r) | PiSSA(s) | MiLoRA(s) | 论文建议的中间 s |
|------|-----------|-----------|---------|----------|-------------|
| ViT-Base | 768 | 32 | 0 | 736 | **256** |
| LLaMA-2 7B | 4096 | 128 | 0 | 3968 | **2048** |

推荐的中间值是**大约在奇异值谱的 1/3 到 1/2 处**（ViT: 256/768 ≈ 33%；LLaMA: 2048/4096 = 50%）。

### 2.3 与其他方法的对比

论文提出一个三角图（Figure 2）总结三者的关系：

```
          SVD
W = U · D · V^T
     \      /
      \    /
       \  /
  ┌─────────────┐
  │   PiSSA:    │  s=0（首分量）
  │ A=U₀:ᵣ√D₀:ᵣ│
  │ B=√D₀:ᵣV₀:ᵣ│
  └──────┬──────┘
         │ 差异
  ┌──────v──────┐
  │   本文方法:  │  s=中间（中间分量）
  │ A=Uₛ:ₛ₊ᵣ√Dₛ:ₛ₊ᵣ│
  │ B=√Dₛ:ₛ₊ᵣVₛ:ₛ₊ᵣ│
  └──────┬──────┘
         │ 差异
  ┌──────v──────┐
  │  MiLoRA:    │  s=m-r（末分量）
  │ A=Uₘ₋ᵣ:ₘ√Dₘ₋ᵣ:ₘ│
  │ B=√Dₘ₋ᵣ:ₘVₘ₋ᵣ:ₘ│
  └─────────────┘
```

三者共享完全相同的公式结构，唯一的区别是 $s$ 的取值。

## 3. 实验设计

### 3.1 图像分类实验

- **基础模型**：ImageNet1k 预训练的 ViT-Base
- **LoRA 配置**：rank $r=32$, scaling factor $\alpha=32$, AdamW (LR=2e-5, weight decay=0.01)
- **训练轮数**：200 epochs
- **起始点测试范围**：$s \in \{0, 4, 16, 32, 64, 128, 256, 512, 736\}$
- **指标**：
  - 下游任务准确率 (Accuracy)
  - 遗忘量 (Forgetting) = |微调前在 ImageNet1k 上的准确率 - 微调后在 ImageNet1k 上的准确率|
  - 准确率和 (Sum of Accuracies) = 下游准确率 + 微调后 ImageNet1k 准确率

### 3.2 NLP 实验

- **基础模型**：LLaMA-2 7B
- **LoRA 配置**：rank $r=128$, 三种训练设置对比
- **起始点测试范围**：$s \in \{0, 1024, 2048, 3072, 3968\}$
- **任务**：Python 编程 (Human-eval, MBPP)、数学推理、常识推理
- **三种训练设置**：
  1. **PiSSA 设置**：LR=2e-5, batch size=128, cosine scheduler
  2. **MiLoRA 设置**：rank=64, LR=3e-4, dropout=0.05, batch size=16
  3. **本文设置**：rank=128, **高学习率** (LR=3.5e-4/3e-4/1e-4), batch size=128, cosine scheduler

### 3.3 理论分析实验

在参数空间和特征空间分析微调对不同主成分的影响：

1. **参数空间分析**：将微调后的权重投影到原始 SVD 坐标系，分解为：
   - 对角线变化 $\text{diag}(\Delta_{\mathcal{W}})$：主奇异值的缩放变化
   - 非对角线变化 $\text{offdiag}(\Delta_{\mathcal{W}})$：主方向的旋转变化

2. **特征空间分析**：类似地分析模型输出特征的变化

3. **加权遗忘分析**：通过将每个主成分置零并测量遗忘量，构造"期望遗忘"权重 $p_i$，然后计算加权和对角线/非对角线变化。

## 4. 核心结果

### 4.1 U 形遗忘曲线

**最重要的发现**：当模型被微调足够长的时间（达到高准确率）时，遗忘量沿奇异值谱呈现**U形曲线**——极端主成分（PiSSA 和 MiLoRA）的遗忘量最高，中间主成分的遗忘量最低。

```
遗忘量 (Forgetting)
      ^
      |      U 形曲线
      |    /          \
      |   /            \
      |  /              \
      | /                \
      |/                  \
      +------------------------> 主成分索引
     s=0(PiSSA)   中间     s=m-r(MiLoRA)
```

这一模式在**所有 11 个视觉数据集**上一致出现（Figures 9, 11-20）。

### 4.2 准确率饱和现象

当下游任务训练足够长时间后：
- **下游任务准确率**在所有起始点 $s$ 上**趋于相同**（plateau）
- **遗忘量**则呈现 U 形
- 因此**准确率和（下游任务 + 预训练任务）在中间成分处达到最大**

### 4.3 量化结果（Table 1）：Vision

| 指标 | PiSSA (s=0) | Ours(s=256) | Ours(Best) | MiLoRA(s=736) |
|------|------------|------------|-----------|--------------|
| Average Sum of Accs | 164.89 | **167.65** | **167.87** | 166.52 |

在 11 个数据集的平均上，本文方法优于 PiSSA 约 3 个百分点、优于 MiLoRA 约 1.4 个百分点。

### 4.4 NLP 结果（Table 2）：Python Coding

| 方法 | Average Accuracy ↑ | Forgetting ↓ |
|------|-------------------|-------------|
| PiSSA | 34.31 | 3.19 |
| PiSSA (ours, high LR) | 37.85 | 4.71 |
| **Ours (s=2048)** | **42.41** | **3.70** |
| MiLoRA | 39.42 | 3.59 |
| MiLoRA (ours, high LR) | 29.71 | 5.25 |

中间分量 (s=2048) 在准确率上显著领先，同时遗忘量处于较低水平。

### 4.5 对高学习率的鲁棒性

**关键发现**：在高学习率设置下：
- 极端主成分 → 容易梯度爆炸 → 导致大量遗忘（甚至训练崩溃）
- 中间主成分 → **保持稳定收敛，无梯度爆炸**
- Figure 10 中，PiSSA 和 MiLoRA 在高学习率下的箱线图显示明显异常值（outliers），而中间成分没有

### 4.6 参数/特征空间分析结果

- Figure 3-4（参数空间）：微调极端成分对**第一个主成分（最大奇异值）造成更大的损伤**
- Figure 6-7（特征空间）：类似但更明显的 U 形
- Figure 5（加权分析）：尽管"期望遗忘"随主成分索引单调递减（蓝色线），但实际加权对角线和（红色线）呈现 U 形——说明极端成分微调导致更大的实际损伤
- Figure 8（特征空间加权）：U 形更加明显

## 5. 作者自述局限

论文中作者提到的缺陷/局限性：

1. **无显式局限性章节**：论文没有单独的"Limitations"章节。

2. **隐含局限**：
   - 实验仅覆盖了 ViT-Base 和 LLaMA-2 7B 两种基础模型，未验证更大规模模型（如 LLaMA-70B、GPT 级别）或其他架构（如 Mixture-of-Experts）
   - 秩的选择固定（vision: r=32, NLP: r=128），未系统研究不同秩下的行为
   - 推荐的"中间"分量起始点（如 s=256 for ViT）是通过经验确定的，缺乏自适应的选择策略
   - NLP 实验中，高学习率设置虽然效果好，但缺少对最优学习率的理论指导

3. **未来方向**（Conclusion 中提及）：
   - 设计有针对性的干预手段，如"选择性秩剪枝"或"方向约束更新"
   - 进一步推进大规模持续学习场景下的可靠性
