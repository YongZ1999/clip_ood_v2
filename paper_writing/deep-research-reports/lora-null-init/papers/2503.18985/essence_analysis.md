# LoRA Subtraction for Drift-Resistant Space in Exemplar-Free Continual Learning 本质分析

## 核心公式推导（严谨推导）

### 预备：LoRA 基础上的 EFCL 设定

在 EFCIL 设定下，模型从任务流 $\{1, 2, \dots, T\}$ 中顺序学习，每个任务 $t$ 对应互不重叠的类别集合 $\mathcal{Y}_t$。训练任务 $t$ 时，只可访问数据集 $\mathcal{D}_t$，无任何来自之前任务的样本。

采用 PEFT 框架：使用预训练 ViT 模型 $\mathcal{M}_{\theta_0}$（参数 $\theta_0$，即 $\mathbf{W}_0$），对每个任务 $t$ 扩展一个 LoRA 分支 $\Delta \mathbf{W}_t = \mathbf{B}_t \mathbf{A}_t$，其中 $\mathbf{A}_t \in \mathbb{R}^{r \times d}$（降维矩阵），$\mathbf{B}_t \in \mathbb{R}^{d \times r}$（升维矩阵），$r \ll d$。

第 $t$ 个任务训练后，第 $l$ 层线性层权重为：
$$
\mathbf{W}_t^l = \mathbf{W}_0^l + \Delta \mathbf{W}_t^l = \mathbf{W}_0^l + \sum_{j=1}^t \mathbf{B}_j^l \mathbf{A}_j^l \tag{1}
$$

### Stage 1: LoRA Subtraction (LoRA⁻) — 构造 Drift-Resistant Space

**动机**：不在旧任务的特征空间中进行建模（因为旧数据不可用），而是在**参数空间**中直接消除旧任务的影响，为新任务的学习构建一个"抵抗漂移"的空间。

**步骤 1：定义任务向量**

受 Task Arithmetic (Ilharco et al., 2023) 启发，任务 $t-1$ 完成后的任务向量为：
$$
\mathbf{V}_{t-1}^l = \mathbf{W}_{t-1}^l - \mathbf{W}_0^l = \sum_{j=1}^{t-1} \mathbf{B}_j^l \mathbf{A}_j^l \tag{2}
$$

**步骤 2：LoRA Subtraction — 从预训练权重中减去旧任务的 LoRA 权重**

$$
\widetilde{\mathbf{W}}_t^l = \mathbf{W}_0^l - \mathbf{V}_{t-1}^l = \mathbf{W}_0^l - \sum_{j=1}^{t-1} \mathbf{B}_j^l \mathbf{A}_j^l \tag{3}
$$

> **这步操作的直觉**：将预训练权重 $\mathbf{W}_0$ 作为"基线"，减去旧任务学到的所有 LoRA 适配器权重（累积任务向量），相当于让模型"遗忘"旧任务的知识。此时的模型 $\widetilde{\mathbf{W}}_t$ 在面对新任务数据时，"看不出"旧任务曾经带来的参数变化，因此新任务输入特征将更少地受到旧任务知识的影响。

**步骤 3：在 LoRA Subtraction 后的模型上计算新任务输入特征**

将新任务数据 $\mathcal{D}_t$ 送入带有 $\widetilde{\mathbf{W}}_t$ 的模型，得到第 $l$ 层的输入特征矩阵：
$$
\widetilde{\mathbf{X}}_t^l = f(\mathcal{D}_t, \widetilde{\mathbf{W}}_t^l) \in \mathbb{R}^{n_t \times d} \tag{4}
$$

然后计算无中心协方差矩阵：
$$
\mathbf{\Sigma}^l = \frac{1}{n_t} (\widetilde{\mathbf{X}}_t^l)^T \widetilde{\mathbf{X}}_t^l \in \mathbb{R}^{d \times d} \tag{5}
$$

### Stage 2: 在 DRS 中训练新任务

**步骤 4：对协方差矩阵做 SVD 构建 DRS 投影矩阵**

$$
\mathbf{U}^l \mathbf{\Lambda}^l (\mathbf{U}^l)^T = \text{SVD}(\mathbf{\Sigma}^l) \tag{6}
$$

选择前 $k$ 个最大特征值对应的主成分方向：
$$
\mathbf{P}^l = (\mathbf{U}^l)_k \in \mathbb{R}^{d \times k}, \quad k \text{ 满足 } \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i} \ge \epsilon \tag{7}
$$

**步骤 5：将梯度投影到 DRS**

在每个训练步 $s$，计算当前任务损失 $\mathcal{L}_{total}$ 关于 LoRA 权重的梯度 $\mathbf{g}_{t,s}^l$，然后投影：
$$
\Delta \mathbf{w}_{t,s}^l = \mathbf{P}^l (\mathbf{P}^l)^T \mathbf{g}_{t,s}^l \tag{8}
$$

权重更新：
$$
\mathbf{W}_{t,s+1}^l = \mathbf{W}_{t,s}^l - \alpha \Delta \mathbf{w}_{t,s}^l \tag{9}
$$

### 完整训练算法 (Algorithm 1)

```
for t = 1 to T:
    if t > 1:
        # Stage 1: LoRA Subtraction
        计算 DRS 投影矩阵 P^l (公式 6-7)
    
    # Stage 2: 在 DRS 中训练
    扩展 LoRA 分支 ΔW_t = B_t A_t
    while not converged:
        采样 batch
        计算梯度 g
        投影梯度: Δw = P(P)^T g  (t>1 时)
        更新权重
```

## 核心假设（显式 + 隐式）

### 显式假设

1. **PEFT 有效性假设**：预训练 ViT 模型提供的通用特征表示可以通过 LoRA 低秩适配器有效地适应下游任务。这是所有 PEFT-based CL 方法共有的假设。

2. **任务向量的可减性假设**：基于 Task Arithmetic (Ilharco et al., 2023)，假设通过在参数空间中**减去**旧任务的 LoRA 权重，可以有效地"遗忘"旧任务的知识，而不会对模型的其他能力产生严重影响。

3. **PCA 主成分保留假设**：DRS 通过保留协方差矩阵的最大奇异值方向来选择对新任务最重要的特征方向。这假设了新任务的最重要学习方向正好是 DRS 保护的方向。

4. **梯度在输入特征张成的空间中**：$"$the gradient update in a linear layer lies within the span of the input data" (引用了 Zeng et al., 2019 和 Wang et al., 2021)。这是 DRS 投影操作有效的理论基础。

### 隐式假设

> **假设 A — "遗忘即稳定"的对偶性假设**
>
> **在哪里引入**：Stage 1 中 LoRA Subtraction 公式 (3) 和 DRS 的构造方式。
>
> LoRA⁻ 的哲学是：**通过"遗忘"旧任务的知识来"保护"旧任务的知识**。这听起来像一个悖论——减去了旧任务的 LoRA 权重看似消除了旧任务知识，但论文的实际论证是：这种"遗忘"只是暂时重置了新任务输入特征空间，使新任务的学习不"看到"旧任务的偏置，从而不产生干扰。旧任务知识的保留是通过对新任务梯度进行 DRS 投影来实现的，而非依赖 LoRA Subtraction 后的权重本身。
>
> 这个假设隐含了一个关键的对偶性：**"遗忘旧知识在特征空间中的影响"等价于"保护旧知识不被新知识干扰"**。这并非显然成立——一个严格意义上来说，LoRA Subtraction 构造的 $\widetilde{\mathbf{W}}_t$ 是一个偏离了预训练分布的权重，在其上计算的特征空间可能包含伪影（artifact），而这些伪影可能包含干扰性信息。
>
> **在什么条件下成立**：当任务向量的影响是"可逆的"（即减去后不产生副作用）时。
>
> **可能不成立的条件**：当旧任务的 LoRA 适配器之间存在非线性交互（interaction）时，简单的线性减法可能无法 cleanly 消除它们的联合影响。

> **假设 B — 协方差矩阵在 LoRA Subtraction 之后的"干净性"假设**
>
> **在哪里引入**：Stage 1 结尾，公式 (5) 和后续的 SVD。
>
> 论文假设在 $\widetilde{\mathbf{W}}_t$ 上计算得到的协方差矩阵 $\mathbf{\Sigma}^l$ 是"干净"的——即它主要反映了新任务自身的特征结构，而不包含旧任务的残留影响。但这个假设依赖于 LoRA Subtraction 的**完全性**：只有完全消除了旧任务的所有影响，协方差矩阵才真正"干净"。
>
> 实际上，$\widetilde{\mathbf{W}}_t = \mathbf{W}_0 - \sum_{j=1}^{t-1}\mathbf{B}_j\mathbf{A}_j$ 是一个低秩修正后的权重。由于 $\mathbf{B}_j\mathbf{A}_j$ 是低秩的（rank = r），LoRA Subtraction 仅在不超过 $(t-1)r$ 维的子空间中对 $\mathbf{W}_0$ 做了修改。**所以 LoRA Subtraction 仅仅在低秩子空间中"遗忘"了旧任务——没有消除旧任务在 $\mathbf{W}_0$ 的全秩空间中的残留影响。**
>
> **在什么条件下成立**：当旧任务的知识基本上全部编码在低秩适配器中（即 $\mathbf{B}_j\mathbf{A}_j$ 捕获了所有与旧任务相关的权重变化）。
>
> **可能不成立的条件**：如果旧任务的知识有一部分溢出到 $\mathbf{W}_0$ 的其他方向（即全参数微调与 LoRA 微调之间的差距），那么简单的 LoRA Subtraction 无法消除这部分溢出。

> **假设 C — DRS 投影的"无偏性"假设**
>
> **在哪里引入**：公式 (8) 中梯度投影操作 $\mathbf{P}^l(\mathbf{P}^l)^T$。
>
> DRS 的梯度投影只保留 $\mathbf{U}^l$ 中**最大的** $k$ 个方向，而丢弃了最小的 $d-k$ 个方向。这假设了新任务需要更新的最重要方向刚好落在 $\mathbf{\Sigma}^l$ 的主成分方向上。但这个$\mathbf{\Sigma}^l$ 是在 LoRA Subtraction 后的模型上计算的——它反映的是**在"遗忘"了旧任务后的新任务特征结构**，而不是"实际需要更新以学习新任务的方向"。
>
> **在什么条件下成立**：新任务的主要变差方向（高方差方向）即为其学习所需的主要更新方向。
>
> **可能不成立的条件**：当新任务的判别信息出现在低方差方向时（即"次要但关键"的信息）。

> **假设 D — 特征漂移的累积近似线性假设**
>
> **在哪里引入**：整个方法的框架设计中。
>
> LoRA⁻ DRS 通过每步的任务向量线性减法来处理特征漂移。这隐含假设了：**特征漂移在累积上是近似线性的，可以通过参数空间中的线性操作来抵消**。但实际上，神经网络的特征漂移是高度非线性的——前几层的微小权重变化经过 ReLU/GELU/LayerNorm 等非线性层后会被显著放大或扭曲。
>
> **在什么条件下成立**：当 CL 中每个任务的分布偏移不大时，漂移可能近似线性。
>
> **可能不成立的条件**：当任务间的分布差异很大时，非线性放大的漂移很难用简单的参数减法来修正。

> **假设 E — ATL 对"新类 vs 旧原型"距离假设**
>
> **在哪里引入**：公式 (13-15) 中 Augmented Triplet Loss 的定义。
>
> ATL 使用旧任务的类原型 $\mathcal{P}_{t-1}$ 作为负样本。这假设旧任务的原型在 DRS 的保护下**仍然有效**——即没有发生显著漂移。如果 DRS 的保护效果不够理想，旧任务原型已经漂移，那么用漂移后的原型作为负样本来计算距离是不准确的，会产生错误的约束信号。这正是 Tab.7 中 InfLoRA + ATL 性能下降的根本原因：**不充分的漂移控制 + ATL = 错误的约束 → 性能下降**。
>
> **在什么条件下成立**：DRS 的漂移控制足够强，使旧任务原型保持有效。
>
> **可能不成立的条件**：DRS 失效时，ATL 会适得其反。

## 与前驱工作的逻辑关系

### 继承了谁的思路/方法？

1. **Task Arithmetic (Ilharco et al., 2023)** —— LoRA Subtraction 的直接理论基础。Task Arithmetic 证明了通过加/减任务向量可以在权重空间中编辑模型（添加知识 = 正向量，删除知识 = 负向量）。LoRA⁻ 将这一思想引入 CL：先用负向量"删除"旧任务知识，再用正向量"学习"新任务。

2. **LoRA (Hu et al., 2021)** —— 所有参数更新的基础架构。

3. **Adam-NSCL (Wang et al., 2021)** —— 继承了"通过梯度投影到特征协方差的零空间来防止遗忘"的核心方法论。DRS 的操作（梯度投影）与 Adam-NSCL 的 null space projection 在形式上高度相似。但不是将梯度投影到"\*\*零\*\*空间"（奇异值为 0 的方向），而是投影到"\*\*主成分\*\*空间"（奇异值最大的方向）。**这一点是本质差异。**

4. **InfLoRA (Liang & Li, 2024)** —— 同样试图构造干扰最小化的子空间用于 CL 中的 LoRA 训练。但 InfLoRA 用旧任务的梯度信息构造子空间，而 LoRA⁻ 用新任务在 LoRA Subtraction 后的输入特征构造 DRS。

5. **Null Space 方法族** (e.g., AdNS: Kong et al., 2022) —— 梯度投影到某一空间的思路与 null space 方法一致，但投影的目标空间含义完全不同。

### 解决了前人的什么根本局限？

**Limitation 1：静态统计量无法捕获动态特征空间**

这是最核心的局限。InfLoRA、Adam-NSCL、EASE 等所有现有方法都依赖**从旧任务存储的静态信息**（梯度、特征协方差、原型等）来构建干扰最小化空间。但随着 CL 任务数增加，特征空间在**持续变化**，这些存储的信息变得越来越过时，导致性能断崖式下降（Tab.2-3 中 InfLoRA 和 Adam-NSCL 在 50-task 设定下 ACC₅₀ 急剧下降）。

LoRA⁻ 的解决方式：**不存储任何旧任务的统计数据，而是在参数空间中直接消除旧任务的影响**。DRS 在每个新任务到来时**重新计算**，基于的是当前模型状态，因此不需要"预测"特征空间的动态变化。

**Limitation 2：存储开销和隐私问题**

Adam-NSCL 等需要存储旧任务的特征协方差矩阵或其 SVD 结果。在长任务序列中，存储开销累积。LoRA⁻ 不需要存储任何旧任务数据，只需保留之前的 LoRA 适配器参数（PEFT 的标准做法），在存储和隐私方面都有显著优势。

**Limitation 3：梯度投影导致的塑性损失**

将参数限制在子空间中往往会限制模型的塑性（plasticity）。LoRA⁻ 结合 ATL 来缓解这一问题——明确设计了增强类间分离的目标，在稳定的 DRS 基础上提供额外的塑性增益。Tab.5 显示 ATL 贡献了 1.2-1.9% 的 ACC 提升。相比之下，Tab.7 显示 InfLoRA + ATL 反而下降，说明只有 DRS 提供了足够有效的漂移控制时，ATL 才能发挥作用。

### 引入/改变了什么约束/假设？

**从"旧空间约束"到"新空间构建"的范式转变**：

- 前人方法（InfLoRA, Adam-NSCL, EASE）的逻辑是：**"旧任务的空间应该被保护"** → 使用旧任务的静态信息来定义一个空间 → 将新任务的学习约束在这个空间中 → 但空间是静态的而特征是动态的 → 漂移。

- LoRA⁻ 的逻辑是：**"旧任务的影响应该被消除"** → 在参数空间中减去旧任务 → 基于"干净"的模型为新任务构建学习空间 → 不依赖任何旧任务信息 → 空间总是最新的 → 抵抗漂移。

**关键约束变化**：前人方法要求存储旧任务信息 → LoRA⁻ 抛弃了这一要求；前人方法要求子空间在任务间保持一致 → LoRA⁻ 允许子空间随任务变化（通过重新计算 DRS）。

## 留下的开放问题

### 悬而未决的问题

1. **LoRA Subtraction 在长序列中的累积误差**：公式 (3) 中 $\widetilde{\mathbf{W}}_t = \mathbf{W}_0 - \sum_{j=1}^{t-1} \mathbf{B}_j \mathbf{A}_j$ 是线性减法。当 $t$ 很大时（如 50），累积的 LoRA 权重减去 $\mathbf{W}_0$ 可能导致权重偏离预训练分布过远。论文没有讨论这种长期累积是否会导致 DRS 的劣化。

2. **DRS 的 k 值选择策略**：公式 (7) 的累积方差阈值 $\epsilon$ 的取值可以显著影响性能，但论文没有详细讨论它的敏感性分析和不同数据集/任务序列下的最优选择。

3. **为什么 DRS 是"主成分空间"而非"零空间"？** 这是本文与 Adam-NSCL 最本质的区别。Adam-NSCL 将梯度投影到旧任务特征协方差的**零空间**（小奇异值方向），而本文的 DRS 取的是**主成分空间**（大奇异值方向）——但 DRS 是在 LoRA Subtraction 后的模型上计算的，所以"主成分"的含义需要重新理解。论文没有深入解释这一选择的理论基础。

4. **ATL 中 margin 参数 $\epsilon$ 和权重 $\lambda$ 的交互**：ATL 的有效性高度依赖 DRS 的效果，但这两种组件之间可能存在高阶交互。论文没有分析 $\epsilon$ 和 $\lambda$ 的联合敏感性。

5. **模型选择偏差**：只在 ViT-B/16 上实验。在更大规模模型（ViT-L/H）或其他架构（Swin, ConvNeXt）上的表现未知。

### 明显但论文没做的实验/分析

1. **与 Adam-NSCL 的"零空间 vs 主成分空间"消融**：如果将 Adam-NSCL 中的零空间投影替换为本文的 DRS 主成分投影，或者反过来将本文的 DRS 投影替换为零空间投影，性能如何？这一消融可以直接定位 DRS 定义方式对性能的贡献。

2. **LoRA Subtraction 与直接去掉旧 LoRA 的对比**：如果不做减法（即直接用 $\mathbf{W}_0$ 代替 $\widetilde{\mathbf{W}}_t$）来计算 DRS，效果如何？这可以量化 LoRA Subtraction 本身的贡献和必要性。

3. **长任务序列的 DRS 质量退化分析**：在 50 个任务后，DRS 是否还能有效捕获新任务的关键方向？有没有量化指标来衡量 DRS 的质量（如奇异值分布的变化）随任务数的退化？

4. **旧类原型的更新机制**：ATL 使用旧原型作为负样本，但论文没有说明原型是否更新、如何更新。如果原型不更新，在 DRS 不完全保护时，原型的漂移会导致 ATL 提供错误信号。

5. **任务顺序敏感度**：CL 中常见的问题。论文没有报告不同任务顺序下的性能稳定性。

### 如果我来改进这篇工作，我会从哪里入手？

1. **理论解释 DRS 为何取主成分而非零空间**：提供更充分的数学论证，解释为什么在 LoRA Subtraction 后的"遗忘"模型上，主成分方向构成了有效的 DRS 而零空间方向不行。这可能涉及分析 $\widetilde{\mathbf{W}}_t$ 的模型如何编码"干净的"新任务特征空间。

2. **引入累积遗忘补偿机制**：对于长序列，LoRA Subtraction 可能导致权重偏移。可以在减法后加一个小的修正项 $\delta$（如 $\widetilde{\mathbf{W}}_t = \mathbf{W}_0 - \sum \mathbf{B}_j \mathbf{A}_j + \delta$），其中 $\delta$ 补偿累积的低秩分解误差。

3. **动态 DRS 融合策略**：每个任务的 DRS 不同，可以在训练过程中逐渐融合历史 DRS 信息，避免每步"从零开始"构建 DRS 导致的信息丢失。

4. **ATL 的交替训练策略**：在 DRS 训练步骤和自由训练步骤之间交替，在 DRS 保护旧知识的同时允许一定的塑性释放空间。

5. **跨模态扩展**：在 NLP 的 CL 设定下验证（如类增量式语言模型训练、持续机器翻译等）。

## 在领域中的范式定位

### 所属范式/技术路线

**EFCL 下的三叉路线：**

```
Exemplar-Free Continual Learning (EFCL)
├── Architecture-based (参数冻结/扩展)
│   ├── DER (Yan et al., 2021): 动态扩展表征
│   ├── FOSTER (Wang et al., 2022): 特征增强+压缩
│   └── SSRE (Zhu et al., 2022): 自持表征扩展
├── Regularization/Knowledge Distillation
│   ├── LwF (Dhar et al., 2019): 输出约束
│   └── PASS (Zhu et al., 2021): 自监督增强
└── Subspace-based (子空间投影)
    ├── Adam-NSCL (Wang et al., 2021): cov → null space
    ├── AdNS (Kong et al., 2022): 进阶零空间
    ├── InfLoRA (Liang & Li, 2024): 梯度子空间
    ├── EASE (Zhou et al., 2024): 可扩展子空间集成
    └── LoRA⁻ DRS (本文): LoRA Subtraction + DRS 投影
```

LoRA⁻ DRS 在子空间投影路线中占据了独特的位置——它抛弃了"使用旧任务数据构建子空间"的共同范式，转而使用"在参数层面先遗忘旧任务、再基于新任务数据构建子空间"的逆操作范式。

### DRS 与 Null Space、正交空间的关系

这是理解本文的核心概念关节点：

**Null Space（零空间）**：
- Adam-NSCL 定义的零空间：旧任务特征协方差矩阵 $\mathbf{\Sigma}_{\text{old}}$ 的零空间（奇异值为 0 的方向）。梯度投影到零空间 = 不对旧任务产生干扰。
- 本质：**"什么方向的变化对旧任务没有影响"** → 找到一个完全不改变旧任务表征的方向集。
- 约束目标：**最小化对旧任务的干扰。**

**Oliver Space / Orthogonal Space（正交空间）**：
- InfLoRA 的"干扰自由空间"：旧任务梯度信息定义的正交子空间。
- 本质：**"什么方向的变化与旧任务所需方向正交"**。
- 约束目标：**最小化新旧任务梯度方向的冲突。**

**DRS（Drift-Resistant Space）**：
- 本文定义的 DRS：在 LoRA Subtraction 后模型上，新任务输入特征协方差矩阵的**主成分子空间**。
- 本质：**"在对旧任务影响最小的前提下，新任务最重要特征方向是什么"** → 一个新任务特有的主成分空间。
- 约束目标：**在新任务自由学习+同时不干扰旧任务。**

**三者的关键区别：**

| 概念 | 基于什么数据 | 取什么方向 | 哲学 |
|------|------------|-----------|------|
| Null Space (Adam-NSCL) | 旧任务特征协方差 | 最小奇异值方向（≈0） | "不要碰到旧任务" |
| Orthogonal Space (InfLoRA) | 旧任务梯度 | 与旧任务梯度正交 | "不要冲突" |
| **DRS (Ours)** | **新任务在"遗忘模型"上的特征** | **最大奇异值方向** | "在新任务的天地里自由学习" |

**为什么 DRS 不叫零空间也不叫正交空间？**

因为 DRS 既不是零空间（取的是最大奇异值方向，不是零奇异值方向），也不是严格的正交空间（没有与任何先验知识进行正交性约束）。它是一个**动态构建的任务特定学习空间**——"抵抗漂移"的特性来自于两步的组合：(1) 先通过 LoRA Subtraction 消除旧任务在参数空间的影响，(2) 再基于"干净"模型的主成分方向限制梯度。

**这实际是在做一个非常巧妙的操作链**：Step A (遗忘) + Step B (限制在受控空间里学习) → DRS 的效果等价于"不干扰旧任务"，但不需要旧任务的任何信息。

### LoRA⁻ DRS 与 InfLoRA / Adam-NSCL 的进一步对比

从 Fig.3 看三种方法随任务数的 ACC 变化：

1. **InfLoRA**（干扰自由空间）：初始 ACC 高但下降快。说明初始任务上的子空间质量好，但随着任务数增加，存储的旧任务梯度统计越来越过时 → 子空间与实际需求的失配加剧。

2. **Adam-NSCL**（零空间）：类似走势，但更早且更陡的下降。说明旧特征协方差的零空间在任务序列变长时退化得更快——因为零空间对统计更新的依赖性更强（"什么方向完全不变"比"什么方向正交"更难精确维持）。

3. **LoRA⁻ DRS**（本文）：持续平稳。因为 DRS 每步都重新计算，不依赖任何过时信息 → 没有"统计量老化"问题。

这揭示了 LoRA⁻ DRS 的本质优势：**不是建得更好，而是不用存也不用猜**。

## 专题分析

### 1. LoRA Subtraction (LoRA⁻) 的核心机制

**它是如何通过"减去旧任务的 LoRA 权重"来建立 Drift-Resistant Space 的？**

完整机制分三层理解：

**第一层（参数层面）：遗忘操作**
$$
\widetilde{\mathbf{W}}_t = \mathbf{W}_0 - \sum_{j=1}^{t-1} \mathbf{B}_j \mathbf{A}_j
$$

在参数空间中，将旧任务嵌入到 $\mathbf{W}_0$ 上的方向（即低秩适配器 $\mathbf{B}_j\mathbf{A}_j$ 所编码的知识）**反向施加**。这等价于"令模型回到未学习旧任务时的状态"。但这里有一个微妙之处：$\mathbf{W}_0$ 本身没有经历旧任务的训练，所以 $\widetilde{\mathbf{W}}_t$ **不是**回到 $\mathbf{W}_0$，而是**走到了 $\mathbf{W}_0$ 的另一侧**。

**第二层（特征层面）：从"干净"的起点看新任务**

将新任务数据 $\mathcal{D}_t$ 喂给 $\widetilde{\mathbf{W}}_t$ 模型。由于 $\widetilde{\mathbf{W}}_t$ 是"遗忘"了旧任务的版本，它对新任务输入的特征提取**不带有旧任务的偏置**。这样得到的 $\widetilde{\mathbf{X}}_t^l$ 是"干净的"——它反映的是新任务在**不被旧任务影响**的状态下的特征结构。

**第三层（投影层面）：在 DRS 内训练新任务**

对"干净"的特征协方差做 SVD 得到 DRS 投影矩阵 $\mathbf{P}^l$。所有梯度更新被限制在这个子空间中。由于 DRS 是基于"干净"特征构建的，其中的方向是对新任务重要但不干扰旧任务的方向。这就是"抵抗漂移"的来源。

**完整链路**：
```
旧任务 LoRA 权重 → 从 W₀ 中减去 → 遗忘的模型
    ↓
新任务数据通过遗忘模型 → 干净的特征 → SVD → DRS
    ↓
梯度投影到 DRS → 新任务更新不干扰旧任务 → 特征漂移被抑制
```

### 这与 SVD-based 初始化方法在哲学上有何不同？

**PiSSA / MiLoRA / LoRA-Null 的 SVD 哲学**：这些方法都对权重矩阵 $\mathbf{W}$（或其投影）做 SVD，目的是**初始化 LoRA 适配器**，确定在微调开始时适配器应该"坐落在"权重空间的哪个位置。它们关心的是一次性任务中的初始化和训练。

**LoRA⁻ 的哲学**：LoRA⁻ **不使用 SVD 做初始化**。SVD 被用于构造**训练时的投影空间**（DRS），而不是用于初始化适配器。LoRA⁻ 中的 LoRA 适配器仍是标准初始化（A 高斯噪声，B 零），真正特殊的机制在于**训练过程中梯度的投影约束**。

> **本质区别**: SVD-based 初始化方法（PiSSA/MiLoRA/LoRA-Null）是"你从哪里出发"的问题，而 LoRA⁻ 是"你往哪里走"的问题。一个是初始化策略，一个是训练约束策略。

**与 InfLoRA 的对比**：InfLoRA 也用 SVD 来构造子空间，但它是基于**旧任务的梯度**来构造子空间（"学什么"），而 LoRA⁻ 的 DRS 基于**新任务在遗忘模型上的特征**（"在哪学"）。InfLoRA 的子空间是"静态的"（旧任务方向），而 DRS 是"动态的"（新任务方向）。

**与 Adam-NSCL 的对比**：两者都是梯度投影方法。Adam-NSCL 投影到旧任务协方差的**零空间**（零奇异值方向），LoRA⁻ 投影到新任务协方差的**主成分空间**（最大奇异值方向）。一个是"不要动"（零空间），一个是"可以在这些方向动但确定的是它们不干扰旧任务"（DRS）。Adam-NSCL 依赖旧数据，LoRA⁻ 不依赖。

### 2. 与主课题（LoRA-Null）的连接

**LoRA-Null 关心的问题**：在**单次微调**中，如何通过 LoRA 初始化保留预训练知识（防止灾难性遗忘）。

**LoRA⁻ 关心的问题**：在**持续学习**中，如何通过训练过程防止特征漂移（防止灾难性遗忘）。

**两种"遗忘"场景的关联**：

| 维度 | LoRA-Null（单次微调知识保留） | LoRA⁻（持续学习漂移控制） |
|------|------------------------------|-------------------------|
| 遗忘来源 | 单次微调中适配器过度拟合下游任务 | 多任务序列中新任务覆盖旧特征 |
| 时间跨度 | 一步（pre-train → fine-tune） | 多步（task 1 → task 2 → ... → task T） |
| 可用信息 | 校准集 + 预训练权重 W₀ | 当前任务数据 D_t（无旧样本） |
| 遗忘对象 | 预训练世界知识 | 过去所有任务的知识 |
| 控制手段 | 初始化阶段（空间选择） | 训练阶段（梯度投影） |

**关联点 1：核心矛盾相同——稳定性和塑性的权衡**

两者都在处理"既要保留旧知识（稳定性），又要学好新知识（塑性）"的张力。LoRA-Null 通过初始化空间约束来解决，LoRA⁻ 通过训练空间约束来解决。

**关联点 2：都使用了"投影"或"空间限制"的思想**

LoRA-Null 将适配器初始化到预训练知识的零空间中 → 微调更新在这个空间中自然发生。LoRA⁻ 将梯度投影到 DRS 中 → 新任务训练不干扰旧任务。两者都是"空间限制"的思路，但作用时机不同。

**关联点 3：LoRA⁻ 给 LoRA-Null 的启发性视角**

1. **"遗忘即保护"的矛盾范式**：LoRA⁻ 最核心的洞察是——通过**消除**旧任务的影响来**保护**旧任务的知识。这个"负负得正"的思路是否可以被引入 LoRA-Null？在单次微调中，是否可以先"遗忘"预训练的某些知识，然后在这些遗忘的知识留下的"空白空间"中学习？

2. **动态空间 vs 静态空间**：LoRA⁻ 的 DRS 是动态构建的（每步重新算），因为它面对的是动态变化的 CL 场景。LoRA-Null 的零空间是静态的（基于校准集一次性计算）。但如果考虑到"微调过程中特征分布也在变化"，是否也需要一个动态更新的初始化或训练空间？

3. **梯度投影的可迁移性**：LoRA⁻ 的 DRS 梯度投影机制可以直接应用到 LoRA-Null 的训练过程中——在 LoRA-Null 初始化后，再加一层 DRS-style 的梯度投影限制，可能进一步减少对预训练知识的干扰。

**关联点 4：最有趣的互补性**

如果把 LoRA-Null 的初始化 + LoRA⁻ 的训练约束结合起来：
- **初始化**：LoRA-Null 方式，将适配器初始化到预训练知识的零空间（确保一开始就不与知识冲突）
- **训练**：LoRA⁻ 的 DRS 投影方式，在训练中进一步约束更新方向（确保训练中也不偏离）

这在理论上可以形成一个"双保险"框架：**初始化防遗忘 + 训练防漂移**。不过，LoRA⁻ 的 DRS 是为 CL 设计的（依赖当前任务数据），在单次微调中要实现等价效果，需要找到一个类似的"遗忘模型"策略——也许可以使用随机初始化或预训练模型自身的噪声来替代。

### 3. Drift-Resistant Space (DRS) 的定义

**DRS 与 Null Space 的关系**：

- **相同点**：都是子空间投影方法，都是将梯度/更新限制到一个特定子空间来防止遗忘。
- **不同点**：DRS 投影到**主成分空间**（PCA-style），Null Space 投影到**零空间**（没有信号的方向）。DRS 不依赖于旧任务数据，Null Space 依赖。

**DRS 与正交空间的关系**：

- **相同点**：都试图找到一个"安全"的更新方向。
- **不同点**：正交空间定义了一个与旧任务**正交**的方向集（需要旧任务信息来定义"正交"），而 DRS 定义了一个对新任务**重要**的方向集（基于新任务自身的信息）。DRS 通过 LoRA Subtraction 绕过了对旧任务信息的需求。

**DRS 的数学定义**：

$$
\text{DRS} = \text{span}\{(\mathbf{U}^l)_k\} \quad \text{其中} \quad \mathbf{U}^l \mathbf{\Lambda}^l (\mathbf{U}^l)^T = \text{SVD}\big( \frac{1}{n_t} (\widetilde{\mathbf{X}}_t^l)^T \widetilde{\mathbf{X}}_t^l \big)
$$

关键是 $\widetilde{\mathbf{X}}_t^l$ 来自 LoRA Subtraction 后的模型——这个模型已经被"净化"了旧任务的知识。

**与主课题的连接总结**：

LoRA⁻ DRS 和 LoRA-Null 虽然来自不同的子领域（CL vs 单次微调），但共享一个核心挑战——**如何在学到新东西的同时不忘记旧的**。LoRA⁻ 提供了一个在 CL 场景下行之有效的动态空间方案，而 LoRA-Null 提供了在单次微调场景下的静态空间方案。两者的结合可能产生一个更通用的"防遗忘"框架。
